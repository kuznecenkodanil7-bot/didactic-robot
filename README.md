# LabyChat Standalone

Автономный клиентский чат-мод для **Minecraft Java Edition 1.21.11** на **Fabric**. Проект написан с нуля и не использует код, API или проприетарные ассеты LabyMod.

> Статус: расширенный MVP / reference implementation. Это не бинарно-идентичная копия закрытого продукта и не обещание совместимости с каждым серверным форматом, который кто-либо когда-либо собрал из цветовых кодов и надежды.

## Главный принцип

Мод работает только на клиенте:

- не регистрирует собственные сетевые каналы;
- не отправляет custom payload-пакеты;
- не подменяет `PacketByteBuf` и сетевой обработчик;
- перехватывает только добавление сообщения в `ChatHud` и его отрисовку;
- хранит исходный `Text`, включая серверные `ClickEvent` и `HoverEvent`;
- отправка обычных сообщений остаётся ванильной; исходящая строка меняется только локальной заменой эмодзи перед стандартным вызовом отправки.

## Реализовано

- собственный лёгкий рендер чата;
- прозрачность, размеры, масштаб шрифта, фон, зебра, позиция и задержка исчезновения;
- анимации `none`, `slide`, `fade`; значение `scale` пока использует безопасный fade fallback;
- аватарки через ванильный асинхронный skin cache;
- зелёный индикатор для игроков, присутствующих в vanilla player list;
- группировка последовательных сообщений одного отправителя;
- временные метки с пользовательским `DateTimeFormatter`-форматом;
- ПКМ-меню: личное сообщение, NameMC, копирование ника;
- пассивный выбор `/msg` или `/tell`, без пробных команд серверу;
- сохранение исходных `run_command`, `suggest_command`, `open_url`, `show_text`, `show_item` и других событий;
- автоматическое превращение обычных `http://` и `https://` ссылок в кликабельные;
- Unicode emoji, `:shortcode:` и безопасные ASCII-замены;
- сканирование пользовательских PNG в `config/LabyChat/emojis/`;
- три встроенные темы и пользовательские JSON-темы;
- blacklist, regex-фильтры, anti-spam со счётчиком;
- упоминания с подсветкой и звуком;
- журнал в `logs/labychat/`, ограниченный максимумом из конфига;
- поиск по журналу через `Ctrl+F` в открытом чате;
- быстрый ответ по `F4`;
- необязательный асинхронный клиент LibreTranslate;
- публичный API для трансформеров, пунктов меню и эмодзи.

## Установка

Потребуются:

- Minecraft Java Edition 1.21.11;
- Fabric Loader 0.18.4 или новее;
- Fabric API 0.141.4+1.21.11;
- Java 21.

Собранный JAR кладётся в папку `mods/` вместе с Fabric API.

## Сборка

Linux/macOS:

```bash
chmod +x gradlew
./gradlew build
```

Windows:

```bat
gradlew.bat build
```

Результат появится в `build/libs/labychat-standalone-0.1.0.jar`. Статус проверки этой поставки описан в [`BUILD_STATUS.md`](BUILD_STATUS.md).

Скрипты загружают Gradle 9.2.1 при первом запуске. При корпоративном прокси можно установить Gradle локально и выполнить `gradle build`.

## Управление

| Действие | Клавиша / команда |
|---|---|
| Настройки | `F8` или `/labychat config` |
| Панель эмодзи | `F7` или `/labychat emoji` |
| Быстрый ответ | `F4` |
| Журнал | `/labychat log` |
| Поиск в журнале | `Ctrl+F` в экране чата |
| Контекстное меню игрока | ПКМ по строке сообщения |

## Конфигурация

Основной файл:

```text
config/LabyChat/config.json
```

Темы:

```text
config/LabyChat/themes/*.json
```

Пользовательские PNG-эмодзи:

```text
config/LabyChat/emojis/*.png
```

Все значения ограничиваются диапазонами из ТЗ при загрузке и сохранении. Экран настроек предоставляет быстрый доступ к основным визуальным параметрам и живое превью; редкие и интеграционные параметры доступны в JSON.

## API

```java
LabyChatAPI.registerMessageTransformer((message, context) ->
        Optional.of(message.copy().append(Text.literal(" ✓"))));

LabyChatAPI.registerContextMenuEntry("my_mod:inspect", new IContextMenuEntry() {
    @Override
    public Text label(ContextMenuContext context) {
        return Text.literal("Inspect " + context.playerName());
    }

    @Override
    public void activate(ContextMenuContext context) {
        // client-only action
    }
});

LabyChatAPI.addEmoji(":my_emoji:", Identifier.of("my_mod", "textures/gui/my_emoji.png"));
```

Подробности: [`docs/API.md`](docs/API.md).

## Известные ограничения

- Статусы AFK / menu между клиентами не передаются: это потребовало бы custom networking и нарушило бы главный запрет проекта.
- Пункты party/guild предоставляются через API, но конкретная интеграция зависит от стороннего мода.
- PNG-эмодзи обнаруживаются и показываются в реестре, однако inline texture-glyph atlas ещё не реализован; в отправляемый чат вставляется shortcode.
- Автоматический title preview URL не выполняется по умолчанию, чтобы не делать скрытые HTTP-запросы по ссылкам из чужих сообщений.
- Выбор внешнего `.ogg` пока не подключён к динамическому resource-pack loader; используется безопасный ванильный звук уведомления.
- Локальная подмена буквального `[item]` без серверного `show_item` не может достоверно восстановить NBT предмета. Настоящий `HoverEvent.ShowItem` сохраняется и работает.
- В этой ветке поддерживается Fabric. Forge и NeoForge потребуют отдельных адаптеров рендера и событий.
